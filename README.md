========================================================

1. PRODUCT CONCEPT

========================================================

SikshaSetu addresses the "Grade-Level Illusion":

Two students can officially belong to the same class while having very different demonstrated learning levels.

The product should help reveal:

"What can this learner actually do?"

The core product experience is:

DECLARE GRADE

→ DIAGNOSE

→ ADAPT

→ UNDERSTAND

→ PRACTICE

→ REASSESS

→ PROGRESS

The official diagnostic flow is:

Diagnostic

→ Sub-skill classification

→ Grade-expectation comparison

→ Teacher-facing summary

The UI must make this concept obvious.
