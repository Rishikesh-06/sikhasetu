# SIKHASETU Learning Intelligence Redesign

## Goal
Rebuild the complete frontend as a distinctive learning-intelligence product while preserving every route, mock interaction, accessibility behavior, and synthetic-data boundary.

## Visual system
- Use a warm ivory canvas anchored by deep ink, cobalt intelligence signals, mint progress, amber attention, and rare coral warnings.
- Pair Instrument Serif editorial statements with Work Sans interface typography and numerical styling.
- Use restrained glass depth only for meaningful overlays, evidence lenses, and spatial controls—not as decoration on every section.
- Create a custom SIKHASETU bridge mark and a recurring “Learning Constellation” language of skill nodes, evidence paths, incomplete routes, and growth signals.
- Replace generic borders, pills, card grids, and sidebar fills with open editorial layouts, fine rules, layered plots, asymmetric hierarchy, and distinctive active markers.

## Landing page
- Build an asymmetric editorial first viewport around the statement “Your grade tells where you’re enrolled. SIKHASETU discovers where you’re ready to learn.”
- Create an interactive Learner Intelligence Map connecting Declared Grade → Adaptive Diagnostic → Skill Evidence → Learning Profile → Personalized Practice → Growth.
- Continue the constellation through the grade-level illusion story, learning process, and role switcher so the visual signature feels structural rather than decorative.
- Preserve all student, teacher, parent, and demo entry points.

## Product experiences
- Redesign the shared desktop navigation as a compact ink rail with a precise active-route marker; create a mobile bottom navigation and compact contextual header rather than a collapsed desktop sidebar.
- Student: lead with a personal My Learning Map, current readiness, demonstrated strengths, and one next step; restyle onboarding, diagnostic, profile, subjects, practice, and progress around skill paths and evidence.
- Teacher: make Class Signal, Skill Distribution, Learning Gaps, Group Opportunities, and Recommended Actions immediately scannable; replace the four-block learning map with an annotated constellation/distribution workspace.
- Assessment: create a focused evidence-observation surface with skill, adaptive challenge, progress, and question state integrated without exam-site styling.
- Groups and learner evidence: use open comparative layouts, connected evidence trails, and clear explanations while retaining all filtering, search, wizard, assignment, and intervention interactions.
- Parent: use a calmer editorial journey with progress paths, milestones, consistency, and supportive next steps without technical overload.

## Reusable implementation
- Add focused primitives for the bridge mark, constellation nodes and paths, evidence labels, glass lenses, section markers, and annotated charts.
- Refactor existing large view files where needed, while keeping mock data and service boundaries unchanged.
- Use the existing React, Tailwind, Lucide, and Recharts stack; add Motion for React only for purposeful transitions and respect reduced-motion preferences.
- Keep semantic tokens in the global design system and use accessible names, focus states, non-color status cues, chart descriptions, and stable responsive dimensions.

## Validation
- Verify every content route and interaction on desktop, tablet, and mobile, including diagnostic progression and exit, student practice completion, teacher search and filters, intervention start, and assessment assignment.
- Inspect rendered pages for overflow, collisions, contrast, typography consistency, chart legibility, route metadata, and console errors.
- Confirm the finished product clearly labels “Demo classroom · Synthetic learning evidence” without dominating the experience.

## Scope boundary
No backend, database, authentication service, real adaptive logic, AI model, scoring engine, or statistical computation will be added.
